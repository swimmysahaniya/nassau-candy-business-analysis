# 🍬 Nassau Candy Business Intelligence Dashboard

An advanced **Business Intelligence & Machine Learning Dashboard** built using **Streamlit, Plotly, Pandas, and Scikit-learn** for analyzing product profitability, forecasting trends, and generating actionable business insights.

---

# 📊 Project Overview

The Nassau Candy Business Intelligence Dashboard helps businesses analyze:

- Product profitability
- Regional performance
- Division-wise contribution
- Profit trends
- Forecasted business growth
- Machine Learning-based profit classification

This dashboard combines:

✅ Business Intelligence  
✅ Interactive Analytics  
✅ Data Visualization  
✅ Machine Learning  
✅ Forecasting  

into a single end-to-end analytics platform.

---

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/swimmysahaniya/nassau-candy-business-analysis.git

```

---

## 2️⃣ Navigate to Project Folder

```bash
cd nassau-candy-business-analysis
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run Streamlit Application

```bash
streamlit run ui/app.py
```
